# Contador 

Projeto desenvolvido para praticar conceitos básicos de **JavaScript** e manipulação de elementos HTML.

## 🚀 Sobre o projeto

O projeto consiste em um contador que permite aumentar ou diminuir o valor exibido na tela através dos botões.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## 📚 Conceitos praticados

- Manipulação do DOM
- Eventos de clique
- Funções
- Variáveis
- Operadores de incremento e decremento
- Alteração de conteúdo HTML

## 🎯 Objetivo

Praticar a utilização do JavaScript para criar uma interação simples entre os elementos da página e as ações realizadas pelo usuário.
